# Contributing

recipe-hub is a personal project, and I'm not taking contributions. Opening pull requests and issues is limited to collaborators.

You're welcome to read the code or fork it under the [MIT License](LICENSE). The brand assets aren't covered by it, so they aren't for reuse (see [License](README.md#license) in the README).

If you find a security problem, please report it privately through the repository's Security tab ("Report a vulnerability") rather than in public.
